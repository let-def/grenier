Module Physh.Set

Sets of objects, compared by physical equality.

type 'a t

A mutable set of elements of type 'a.

val create : unit -> 'a t

create () returns a new, empty set. It does not allocate any storage until the first element is added: empty sets are cheap.

val length : 'a t -> int

length t is the number of elements of t. Constant time.

val is_empty : 'a t -> bool

is_empty t is length t = 0.

val mem : 'a t -> 'a -> bool

mem t x is true if x is an element of t.

val add : 'a t -> 'a -> unit

add t x adds x to t. Does nothing if x is already present.

val add_if_new : 'a t -> 'a -> bool

add_if_new t x adds x to t and returns true if x was already present (in which case t is unchanged). This is the "visited" test of a traversal, in a single lookup.

val remove : 'a t -> 'a -> unit

remove t x removes x from t. Does nothing if x is absent.

val clear : 'a t -> unit

clear t removes all elements of t, keeping its storage for reuse.

val reset : 'a t -> unit

reset t removes all elements of t and releases its storage: t is then as cheap as a new set.

val iter : ('a -> unit) -> 'a t -> unit

iter f t applies f to each element of t, in an unspecified order. f can look up t; if it modifies t, it is unspecified whether the added (or removed) elements are visited.

val fold : ('a -> 'acc -> 'acc) -> 'a t -> 'acc -> 'acc

fold f t acc is f xN (... (f x1 acc)), where x1 ... xN are the elements of t, in an unspecified order. Same restrictions as iter.
