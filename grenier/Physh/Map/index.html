Module Physh.Map

Maps from objects, compared by physical equality, to arbitrary values. A key has at most one binding.

type ('a, 'b) t

A mutable map from keys of type 'a to values of type 'b.

val create : unit -> ('a, 'b) t

create () returns a new, empty map. It does not allocate any storage until the first binding is added: empty maps are cheap.

val length : ('a, 'b) t -> int

length t is the number of bindings of t. Constant time.

val is_empty : ('a, 'b) t -> bool

is_empty t is length t = 0.

val find : ('a, 'b) t -> 'a -> 'b

find t k returns the value bound to k.

  • raises Not_found

    if k is not bound.

val find_opt : ('a, 'b) t -> 'a -> 'b option

find_opt t k returns Some v if k is bound to v, None otherwise.

val mem : ('a, 'b) t -> 'a -> bool

mem t k is true if k is bound in t.

val add : ('a, 'b) t -> 'a -> 'b -> unit

add t k v binds k to v, replacing any existing binding.

val add_if_new : ('a, 'b) t -> 'a -> 'b -> 'b option

add_if_new t k v binds k to v if k is not bound. Returns the previous binding: None if k was absent (it is now bound to v), Some v' if k was bound to v' (left unchanged).

val add_overwrite : ('a, 'b) t -> 'a -> 'b -> 'b option

add_overwrite t k v binds k to v, replacing any existing binding. Returns the previous binding: None if k was absent, Some v' if k was bound to v'.

val remove : ('a, 'b) t -> 'a -> unit

remove t k removes the binding of k. Does nothing if k is not bound.

val clear : ('a, 'b) t -> unit

clear t removes all bindings of t, keeping its storage for reuse.

val reset : ('a, 'b) t -> unit

reset t removes all bindings of t and releases its storage: t is then as cheap as a new map.

val iter : ('a -> 'b -> unit) -> ('a, 'b) t -> unit

iter f t applies f k v to each binding of t, in an unspecified order. f can look up t; if it modifies t, it is unspecified whether the added (or removed) bindings are visited, and which value is passed for an overwritten binding.

val fold : ('a -> 'b -> 'acc -> 'acc) -> ('a, 'b) t -> 'acc -> 'acc

fold f t acc is f kN vN (... (f k1 v1 acc)), where (k1, v1) ... (kN, vN) are the bindings of t, in an unspecified order. Same restrictions as iter.
